# E-Commerce-Sales-Performance-
E-Commerce sales analysis using Excel and Power BI, exploring sales performance, product trends, customer behaviour and key business insights 

Methods: Used SQLite and SQL JOINs, aggregations and customer segmentation to analyse e-commerce customer, order and product data. Created visualisations to examine sales trends, product performance and customer behaviour.

Findings: Identified key revenue-driving products and customer groups, purchasing patterns and sales trends, providing insights that could support marketing and sales decisions.
