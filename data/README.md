## Dataset Information

The dataset contains transactional e-commerce data, including:

- Invoice numbers
- Product descriptions
- Quantities sold
- Invoice dates
- Unit prices
- Customer IDs
- Customer countries

The dataset was cleaned and prepared in Microsoft Excel before being used to create the Power BI dashboard.

## Tools Used

- Microsoft Excel – Data cleaning and preparation
- Power BI – Data modelling, analysis, DAX measures, and dashboard visualisation

> Note: The original dataset is not included in this repository due to its file size. It can be downloaded directly from Kaggle using the link above.
